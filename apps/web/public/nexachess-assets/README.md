# NexaChess visual asset library

Hand-authored vector illustrations (no embedded rasters), served as static
files from `/nexachess-assets/...`.

| Folder | Files | viewBox | Used in the app |
|---|---|---|---|
| `empty-states/` | `empty-{activity,assignments,attendance,courses,notifications,puzzles,reports,schedule,search-results,students}.svg`, each with a generated `-dark.svg` twin | `0 0 240 200` | Yes, through `EmptyState` |
| `chess-pieces/` | `piece-{king,queen,rook,bishop,knight,pawn}.svg` | `0 0 120 160` | Not yet |
| `status/` | `state-{live,success,error,warning,completed,pending,locked,connection-lost,loading,achievement-unlocked}.svg` | `0 0 64 64` | Not yet |
| `achievements/` | `achievement-{first-class,puzzle-master,consistency,tournament-winner,learning-streak,checkmate,course-completion,rating-improvement}.svg` | `0 0 120 120` | Not yet |

## Empty states

Used through `EmptyState` (`illustration="courses"`) or `EmptyStateIllustration`
(`components/ui/EmptyState.tsx`), up to 200px wide. The SVGs hold fixed palette
colours and load as `<img>`, so they can't read the theme tokens: each has a
`-dark` twin, and the component shows one with `dark:hidden` / `hidden dark:block`.

**Edit only the light file.** The twins are generated by
`node apps/web/scripts/nexachess-dark-variants.mjs` (`--check` fails when one
is stale). The script swaps paper and ink (`#FFFFFF`/`#F4F7FC` cards become
`#132D50`, `#0B1F3B` ink becomes `#DBEAFE`), brightens dim blues, deepens ground
shadows, and applies a few per-file fix-ups (boards stay dark, calendar headers
stay blue). A fix-up that stops matching after an edit fails loudly.

## Status and achievements

Both sets are drawn on their own navy tile, so they read on light and dark
surfaces as delivered; no dark twins needed. `state-loading.svg` spins with SMIL,
which also runs inside `<img>`.

Before wiring them in: `docs/UI_RULES.md` makes `lucide-react` the only icon set,
so status tiles belong in places that want a branded badge (live-class banners,
achievement toasts), not as replacements for inline status icons or `Badge`.

## Chess pieces

Decorative brand art for course cards, banners, rank badges and onboarding
headers, not a board piece set: board sets live in `public/chess/pieces/<id>/`
as `w*.svg` + `b*.svg` and are read through `useChessAppearance()`. Gradient ids
are unique per file, so several pieces can be inlined on one page.
