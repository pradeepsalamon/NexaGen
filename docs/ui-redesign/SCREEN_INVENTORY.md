Every route in `apps/web`. Audited across `dev` (`10f307b8`) and `origin/main` (`ae52644e`) on 2026-11-01, then updated for the merged branch `redesign/design-system-v2`: `/academy` is now a redirect, `/admin/class-requests` is now a redirect, and `/admin/requests` and `/coach/requests` are new. **Nothing in this document has been built.** References to `dev` or `main` describe those branches at audit time. Decision references are settled in [REDESIGN_ROADMAP.md](REDESIGN_ROADMAP.md) §2.

## How to read this

| Field | Source | Status |
|---|---|---|
| Route, role, title, nav | `app/`, `lib/routeAccess.ts`, `lib/pageTitles.ts`, `navItems.ts` | **Existing** |
| Components, actions, API, states | Generated by tracing each page's imports at symbol level | **Existing.** Reachable in code; not every state was triggered |
| Mobile and tablet | Code counts plus a read-only browser sweep, light theme | **Existing.** Local seed data, so many lists were empty |
| UX problems | Judgement, tagged with its evidence: `[code]`, `[measured]`, `[verdict]`, `[baseline]`, `[docs]` | **Finding** |
| Recommendations | Presentation changes against design system v2 | **Proposed.** Not built, and none removes functionality |

"Controls under 40px" counts visible interactive elements inside `<main>` whose shorter side is under 40px, using the threshold in `docs/UI_RULES.md`. Workflow ids (W1–W38) are defined in [FRONTEND_AUDIT.md](FRONTEND_AUDIT.md#9-major-workflows).

**Actions** lists fixed text labels found in the code, so labels built at runtime, including most `RowActions` entries, are missing. **Read Actions together with the API line:** a `PATCH`, `POST` or `DELETE` entry is an action too.

API entries read `METHOD group.route`, which are `API_ROUTES` keys. `?` means the route is used through a helper that hides the method, such as `useServerTable` or a download link.
