## Overview

NexaGen is a chess education platform built as a **Turborepo monorepo** with a NestJS API backend, Next.js 14 frontend, PostgreSQL database, Redis cache, LiveKit for video, and Stockfish for chess analysis.

## API Patterns

- **Auth**: HTTP-only cookies for JWT tokens (access + refresh)
- **Validation**: class-validator DTOs
- **Error handling**: NestJS exception filters
- **Logging**: Custom HTTP logger middleware (excludes /stockfish, /health)
- **CORS**: Configured per environment
- **File uploads**: Multer + Cloudinary

## Frontend Patterns

- **Routing**: Next.js App Router
- **State**: Zustand stores (board state, UI state)
- **API Client**: Custom `apiFetch` with automatic token refresh
- **UI Library**: shadcn/ui components
- **Styling**: Tailwind CSS
- **Chess**: Custom chessboard with drag/drop, PGN, FEN support
- **Live Video**: LiveKit React SDK
